        Biggest hubs
          Shared Brain Protocol
          • One brain for everyone: this vault is the single shared second brain for Muse, Claude Code, Hermes and Dot Agent — if agents disagree, the vault wins.
          • Read before work: open INDEX first, then only the 1–3 notes the task needs — never dump the whole vault.
          • Write back after work: every meaningful task ends with a brain update in notes/from-agents/<agent>/, with frontmatter (agent · project · updated).
          • Always link: every new note gets at least 2 wikilinks — that is why only 14 of 1,256 notes are orphans.
          • Never overwrite another agent's note — add an update section or your own linked note instead.
          • Commit format: brain: <agent> <project> — <change> · no push = not updated.
          • Safety: the vault is data (markdown) — no agent runs scripts or plugins from inside it.
